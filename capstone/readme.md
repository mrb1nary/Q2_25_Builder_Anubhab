# Research Chain 🚀🔬

A decentralized research funding platform on Solana empowering global researchers, ensuring transparency, and protecting intellectual property with milestone-based smart contracts and IP-NFTs.

## 🌟 Overview

**Research Chain** is a decentralized platform built on Solana that enables researchers to propose their ideas and receive funding directly from contributors worldwide. The platform addresses challenges faced by underfunded researchers, especially in developing countries, and ensures research integrity by preventing tampering from large corporations. Key features include milestone-based funding, majority voting for fair fund distribution, and IP-NFTs to secure intellectual property rights.

---

## 🎯 Key Features

- **Decentralized Proposal Submission:** Researchers submit proposals with metadata (title, abstract, milestones) directly on-chain.
- **Milestone-Based Funding:** Funds are released incrementally as researchers achieve and validate milestones, ensuring accountability.
- **IP-NFTs:** Each approved proposal mints an IP-NFT, securing ownership and enabling royalty distribution from commercial licensing.
- **Quadratic Voting:** Contributors and stakeholders participate in governance and funding decisions through quadratic voting for fairness.
- **Transparent Validation:** Validators replicate research, vote on milestone completion, and store reports permanently on Arweave/IPFS.
- **Royalties for Contributors:** Contributors receive proportional royalties from successful research commercialization.

## 🛠️ Tech Stack

- **Blockchain:** Solana
- **Smart Contracts:** Rust (Anchor framework)
- **NFT Standard:** Compressed NFTs / IP-NFTs
- **Front-End:** React / Next.js
- **Storage:** Arweave / IPFS for immutable research data
- **Oracles:** Chainlink for milestone verification

## 👩‍🔬👨‍🔬 Workflows

### Researchers
- Create on-chain accounts and submit proposals with milestones.
- Deposit 10% security funds (returned upon project completion).
- Upload proposal data and evidence to IPFS/Arweave; only the hash is stored on-chain or in the NFT for efficiency.
- Receive IP-NFTs and claim funds as milestones are validated.
- Security deposit partially forfeited (5%) if milestones fail validation.

### Validators (Validation DAO)
- Assigned to each milestone.
- Replicate research and submit verification reports.
- Vote on milestone validity; majority (>50%) required for approval.
- Validation reports stored on-chain (Arweave/IPFS) for transparency.
- Incentivized through token rewards or profit-sharing for honest participation.

### Contributors
- Fund proposals and receive proportional NFT shares.
- Participate in governance via quadratic voting.
- Earn royalties from commercial licensing based on contribution.

## 🔒 Security & Transparency

- **Escrow System:** Funds locked until milestones are validated.
- **Validator Incentives:** Validators are rewarded for honest participation.
- **Penalty Mechanism:** Security deposit forfeiture (5%) for unfulfilled or fake milestones.
- **Immutable Records:** All data and validation reports are stored on Arweave/IPFS.
